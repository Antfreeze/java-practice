# Практика 6 — Типы стандартной библиотеки

Проект рассчитан на Java 17 и JUnit 5. Основные исходники находятся в `src/main/java`, тесты — в `src/test/java`.

## Запуск тестов

Из каталога `practice6` выполните:

```bash
mvn clean test
```

## Основные решения

- Для сравнения текста используется `String.equals`, а `==` показан только как сравнение ссылок.
- Для денежных вычислений используется `BigDecimal`; `Money` поддерживает явный `RoundingMode` при создании и вычислении процента.
- Распределение денег по частям выполняется в целых копейках, остаток распределяется детерминированно.
- `RandomSampleService` принимает `RandomGenerator`; в тестах можно передавать `new Random(seed)` для воспроизводимого результата.
- `WebinarSeriesPlan.getSchedule()` строит полное расписание в зоне организатора. Интервал `Period` прибавляется к локальному календарному времени; при несуществующем времени после DST Java сдвигает время вперёд на длину разрыва, а при повторённом времени сохраняет предыдущее смещение, если оно допустимо.
- `RefundService` позволяет передать режим округления; по умолчанию используется `HALF_UP`.

В проекте оставлены простые классы и понятные методы без сторонних библиотек в основной логике. Для сборки тестов требуется доступный Maven и загрузка зависимости JUnit 5.
